What the dashboard supports

The dashboard supports exploratory comparison of land-cover products: map + national or sub-basin shares over time, validation against CORINE or cadastre-based references, and exports. It is meant to complement deeper GIS or modelling work, not replace pixel-level accuracy assessment. Raster edges follow the native cell size of each product; smoothing or gap-filling along the country outline would need offline geoprocessing (e.g. mask + focal fill in a GIS), not something the web map can do reliably.
